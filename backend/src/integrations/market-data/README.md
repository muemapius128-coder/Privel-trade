# Market Data Integrations

The Market Data module provides access to external financial data providers.

## Responsibilities

- Live Prices
- Historical Data
- Economic Calendar
- News Feeds
- Sentiment Data
- Corporate Actions
- Market Statistics

## Supported Markets

- Forex
- Cryptocurrency
- Stocks
- Futures
- Commodities
- Indices

## Design Goals

- High Accuracy
- Low Latency
- Data Integrity
- Provider Redundancy
