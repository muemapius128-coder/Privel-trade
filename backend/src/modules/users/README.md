# Users Module

The Users module manages the complete lifecycle of every user within the Privel Trade ecosystem.

It is responsible for user profiles, account management, permissions, organizations, subscriptions, trading portfolios, preferences, and user-related business logic.

This module works closely with the Authentication, Security, Broker, Trading, AI, and Portfolio modules to provide a secure and personalized experience.

---

## Responsibilities

- User account management
- User profiles
- Account settings
- Roles & permissions
- Organizations & teams
- Subscription management
- Portfolio ownership
- User preferences
- Session management
- Activity tracking
- User lifecycle management
